# DRP 穿透式监管系统 · 演示驾驶舱

基于 Vue 3 + Vite + ECharts + G6 的大型集团穿透式监管前端演示系统，覆盖 **10 大重点领域**、**6 大业务场景**，支持 AI 智能体驱动的风险分析和跨域穿透核查。

## 快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 打开浏览器访问
# http://localhost:5173
```

> 推荐 Node.js 18+

## 六大业务场景

| 路由 | 场景 | 核心功能 |
|------|------|----------|
| `#/dashboard` | **风险监控驾驶舱** | 十大重点领域卡片（含呼吸灯 + 风险分进度条）、中国地图机构热力分布、预警趋势图、突发事件列表、资金/责任穿透图、一利五率 KPI |
| `#/invest` | **投资穿透** | 42 个项目矩阵、关联方知识图谱、项目穿透详情、AI 研判、底层资产追踪 |
| `#/finance` | **资金穿透** | 7 级穿透链路：报表 → 科目余额 → 明细科目 → 凭证 → 业务单据 → 合同 → 采购订单、资金流桑基图、拦截规则引擎 |
| `#/equity` | **合同穿透** ⭐ | 30+ 子公司合同智联仓库、合同风险列表（高/中/低三级）、AI 智能体分析弹窗、风险事项详情报告、价格一致性穿透核查（供应商历史 → 询价 → 发票）、合同详情十大类结构化数据 |
| `#/overseas` | **采购穿透** | 招标项目矩阵、围标串标 AI 检测（同IP/同MAC/报价等差/股权关联）、供应商档案、采购工单 |
| `#/ai` | **AI 智能体** | 多 Agent 模型调度、智能问数对话、规则模型库、SkillHub、实时风险事件推送 |

## 核心亮点

### 合同穿透（#/equity）
- **智能合同仓库**：30+ 子公司、32 份合同（万级至亿级金额），按签订时间排序，按风险等级筛选
- **合同卡片三栏分区**：核心信息（合同名称/编号/甲乙方/签订时间）→ 风险标识（最高等级 + 分级明细 2高 1中 1低）→ 金额 + 操作按钮
- **履约进度条**：实际进度 vs 计划进度对比，黑色节点标记计划位置，hover 弹出 tooltip，超进度/滞后自动文字标注
- **风险列表**：7 项必需字段（风险ID、名称、等级、预警时间、涉及主体、关联索引、处理状态），红橙黄三色卡
- **AI 智能体分析弹窗**：深色科技感弹窗，7 步推理动画（启动引擎 → 提取条款 → NLP解析 → 历史比对 → 穿透关联 → 规则验证 → 生成报告），自动跳转风险报告页
- **价格一致性穿透核查**：供应商历史合同（查看历史价格） → 采购询价记录（核查同期市价） → 发票详情（双列对比确认一致性） → 核查结论录入（合理/违规异动）
- **合同详情页**：十大类结构化数据（AI 总览 → 基础主体 → 时效 → 金额费用 → 业务标的 → 履约/结算/合规/关联 → AI 合规审查意见）
- **导航历史栈**：跨页面返回自动识别来源（返回风险报告 / 返回合同详情 / 返回仓库）

### 首页十大重点领域
- **呼吸灯**：高风险红色脉冲 / 中风险橙色脉冲 / 关注黄色脉冲 / 正常无
- **风险分进度条**：渐变配色，直观展示 0-100 风险等级
- **待办数**：独立徽标，红色边框突出

### 全局功能
- **实时提醒铃**：右上角铃铛图标，未读角标 + 脉冲光晕，分域筛选（全部/紧急/一般/通知），点击跳转对应业务页
- **AI 浮动入口**：右下角 AI 智能体快捷入口，全局可用
- **Floating AI 助手**：场景感知对话面板，sessionStorage 持久化消息
- **顶部导航**：智能返回按钮，面包屑式导航标识

## 技术栈

| 层 | 技术 |
|----|------|
| **框架** | Vue 3（Composition API + `<script setup>`） |
| **构建** | Vite 5 + `@vitejs/plugin-vue` |
| **图表** | ECharts 6（通过自定义 `EChart.vue` 包装器） |
| **图可视化** | @antv/g6 4.x（通过自定义 `KnowledgeGraph.vue` 包装器） |
| **路由** | 自定义 hash-based SPA（`window.location.hash` + `KeepAlive` 状态保持） |
| **样式** | CSS Variables + Scoped CSS，支持深色模式覆盖 |
| **数据** | 纯前端 Mock（`src/mock/index.js`，1926+ 行，覆盖 12 个业务域数据集） |
| **字体** | Noto Sans SC、Noto Serif SC、Orbitron、JetBrains Mono |

## 数据规范

`src/mock/index.js` 导出 40+ 个数据集，覆盖：
- 组织架构：30 家子公司 × 5 大板块
- 合同：32 份合同 × 合同风险项集合 × 穿透核查数据
- 资金：银行账户 × 支付订单 × 审批链 × 拦截规则
- 投资：6 个项目 × 资金趋势 × 里程碑 × 关系图谱
- 采购：7 个招标项目 × 投标人 × 供应商画像 × 串通检测
- 财务：费用 × 凭证 × 薪资 × 产权 × 境外 × 金融 × 会计

所有数据集均可平滑替换为真实 API 接口。
