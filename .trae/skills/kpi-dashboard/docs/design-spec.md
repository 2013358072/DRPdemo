# 页面设计规范

## 视觉风格

- 深色渐变背景：`linear-gradient(135deg, #0a0e2e 0%, #1a1f4e 50%, #0d1b3e 100%)`
- 玻璃态卡片：`background: rgba(255,255,255,0.05); backdrop-filter: blur(10px); border: 1px solid rgba(255,255,255,0.1)`
- 主色调：蓝色 `#4fc3f7`、青色 `#00e5ff`、金色 `#ffd54f`（警示）
- 字体：微软雅黑 / PingFang SC fallback

## 3D 翻牌器动画

- 每位数字独立渲染为翻牌单元（`.flip-unit`），包含上/下半面板和翻转动画面板
- 数字变化时：旧数字面板上翻消失（rotateX → -90deg），新数字面板下翻出现（rotateX 90deg → 0）
- 翻转伴随底部阴影脉冲效果，增强立体感
- 变化位从右到左逐位级联翻转（每两位间隔 80ms），未变化的位保持静止
- 首次渲染或位数变化时重建 DOM 结构，后续切换仅翻转变化的位
- 百分比后缀以小字号独立显示（`.flip-suffix`）

## 四套主题

### 默认（深空蓝）

- 深色渐变背景，蓝青色调
- 玻璃态卡片，圆角 12px
- 适合沉稳专业的场景

### 赛博朋克

- 纯黑背景 `#050508`，荧光绿 `#00ffe0` + 荧光粉 `#ff00aa`
- 扫描线叠层动画（`@keyframes scanMove`）
- 标题毛刺故障效果（`@keyframes glitch`）
- 切角卡片（`clip-path`），等宽字体（Courier New）
- 适合科技炫酷的场景

### 星空宇宙

- 黑色背景 `#020b1e` + Canvas 粒子星空
- 蓝紫配色 `#5588ff` / `#aa66ff`
- 大圆角卡片（18px）
- Canvas 2D 粒子：闪烁效果 + 十字光晕 + 缓慢上移
- 适合沉浸浪漫的场景

### 商务蓝白（Corporate）

- 深蓝色渐变背景 `linear-gradient(135deg, #1e3c72 0%, #2a5298 100%)`
- header 背景同步渐变 `linear-gradient(90deg, rgba(30,60,114,0.85), rgba(42,82,152,0.85))`，文字白色
- 白色基调，清晰专业，适合企业正式场景
- 无背景动画，界面干净整洁
- **KPI 卡片**：4 列布局（隐藏"覆盖部门数"和"评分完成率"），渐变色块背景，数字居上、图标居下
  - 考核总人数：蓝色渐变 `#1976D2 → #42A5F5`
  - 已完成评分人数：青绿渐变 `#00796B → #26A69A`
  - 优秀人数 + 优秀率：橙色渐变 `#E65100 → #FFA726`
  - 不合格人数 + 不合格率：红色渐变 `#C62828 → #EF5350`

## 定时刷新模式

- Header 控件区：部门选择器与主题切换之间
- 点击旋转图标 → 开启/关闭自动刷新（默认 30s 间隔）
- 点击下拉箭头 → 选择间隔（30s / 1min / 2min / 5min）
- 激活状态：绿色高亮边框 + 脉冲动画 + 图标持续旋转
- 倒计时显示：激活时标签显示距下次刷新的剩余秒数
- 刷新触发时：图标加速旋转 0.8s，调用 `loadData()` 保持当前年份/部门不变
- 页面卸载自动清理定时器

## 响应式断点规范

### 全屏布局原理

采用 Flexbox 全屏布局，而非固定 `calc(100vh - headerH)` 硬编码：

```
body (flex column, overflow: hidden)
  ├── header (flex-shrink: 0, height: auto)
  └── main (flex: 1, min-height: 0)
```

大屏/桌面模式下页面禁止滚动，main 自动填满剩余空间；平板/移动端切换为 `overflow: auto` 允许自然滚动。

### 4 断点网格配置

| 断点 | 范围 | .kpi-row 列数 | .chart-row 列数 | 特殊处理 |
|------|------|-------------|----------------|---------|
| 大屏 | ≥1920px | `repeat(6, 1fr)` | `1fr 1fr` | 全屏禁止滚动 |
| 桌面 | 1280-1919px | `repeat(3, 1fr)` | `1fr 1fr` | 全屏禁止滚动 |
| 平板 | 768-1279px | `repeat(3, 1fr)` | `1fr 1fr` | 允许滚动，图表 min-height 320px |
| 移动端 | <768px | `repeat(2, 1fr)` | `1fr` | header 折叠，表格字号缩小 |

### 移动端特殊适配

- header：`flex-wrap` 换行，`ctrl-label` 标签隐藏，下拉框缩小
- KPI 卡片：padding 缩小，字号 20px
- 图表卡片：min-height 260px
- 弹窗：宽度 96vw
- 表格：字号 12px，单元格 padding 缩小

### Corporate 主题 KPI 布局覆盖

Corporate 主题在大屏/桌面显示 4 列 KPI（隐藏"覆盖部门数"和"评分完成率"），平板/移动端切换为 2 列。
